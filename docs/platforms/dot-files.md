# Dot.Files — Cloud File Management Platform

**Role:** The Storage and Document Layer of the Dot Ecosystem  
**URL:** `files.infodot.app`  
**Tagline:** Your files, your way, everywhere in the Dot ecosystem.

---

## Vision

Dot.Files is not a cloud drive bolted onto the Dot ecosystem. It is the **shared file layer** that every other Dot platform reads from and writes to. Contracts generated by Dot.Agents, reports exported from Dot.Analytics, invoices from Dot.Finance, and designs from Dot.Design all live in Dot.Files. No platform manages storage independently.

Competitors like Google Drive, Dropbox, and SharePoint are general-purpose tools with no knowledge of the workflows that produce or consume files. Dot.Files knows that a PDF is a contract, that a spreadsheet belongs to a project, that a video was generated by an AI agent — and surfaces that context across the ecosystem.

## Core Features

### File Browser
- Folder and file hierarchy with drag-and-drop organisation
- List and grid views with sort, filter, and search
- Preview for images, PDFs, videos, audio, and plain text
- Bulk select, move, copy, delete, and share
- Recycle bin with configurable retention

### Team Workspaces
- Team-scoped workspaces shared with InfoDot team model
- Permission levels: viewer, contributor, editor, admin
- Activity log per workspace — who uploaded, edited, deleted
- Guest access with expiring share links

### Version History
- Automatic versioning on every file update
- Named versions and version comments
- One-click restore to any previous version
- Version diffing for text-based files

### Sharing and Access Control
- Shareable links with optional password and expiry
- Domain-restricted sharing within the organisation
- Public read links for files intended for external access
- Revoke access at any time without deleting the file

### File Intelligence (AI Layer)
- Auto-tagging by content type: contract, invoice, report, image, code, presentation
- Full-text search inside PDFs, DOCX, and plain text
- Duplicate detection across workspaces
- AI-generated file summaries for documents and PDFs
- Expiry alerts for contracts and dated documents
- Auto-categorisation fed into Dot.Analytics

### Upload and Storage
- Multi-file drag-and-drop upload
- Resumable large file uploads
- Configurable per-workspace and per-user quotas
- Storage backend: AWS S3 via Laravel Flysystem
- MIME type re-detection server-side (security requirement)
- Malware scan integration hook on upload

## InfoDot Integration Notes

Dot.Files is the **first satellite platform** in the ecosystem integration roadmap (Phase 5 of the upgrade plan). It shares the InfoDot PostgreSQL database and authenticates via the `/auth/ecosystem` handoff endpoint.

- 31 open pull requests need triage before full integration
- The shared `users` and `teams` tables are the authority for membership
- File ownership is scoped to `user_id` with team-level sharing via `team_id`
- Storage metadata lives in Dot.Files' own domain tables; binary objects live in S3
